# Krea 2 LoRA 自主训练教程

> 环境位置：`krea2-lora-train\`　训练器：**musubi-tuner**（kohya-ss 出品，官方支持 Krea 2）
> 这套环境是**独立**的，不会影响 ComfyUI 和秋叶包。

---

## 一、能训什么

| 类型 | 用途 | 数据量 | 说明 |
|---|---|---|---|
| **角色 LoRA** | 让模型稳定画出某个人物/OC | 15~40 张 | 最常用，多角度多表情 |
| **画风 LoRA** | 学会某种画风（厚涂/赛璐璐/某画师味） | 30~100 张 | 描述里别写风格词，让 LoRA 吸收 |

Krea 2 的推荐流程是 **在 RAW 模型上训练，在 Turbo 模型上出图**，本套脚本已经按这个来配。

---

## 二、目录与文件一览

```
krea2-lora-train\
├── 1-自动打标.bat          ← 用 Qwen3-VL 自动给图片写描述
├── 2-缓存latent.bat        ← 预缓存图像 latent
├── 3-缓存文本编码.bat       ← 预缓存文本编码器输出
├── 4-开始训练-LoRA.bat      ← ★ 训练（双击就能跑）
├── 5-用新LoRA出图.bat       ← 训练完直接出图看效果
├── .venv\                  ← 独立训练环境（复用系统里的 torch）
├── musubi-tuner\           ← 训练器源码
├── dataset\
│   ├── character\          ← ★ 你的训练图片放这里
│   └── style\              ← 画风数据集（可选）
├── config\
│   ├── dataset_character.toml   ← 数据集配置（角色）
│   └── dataset_style.toml       ← 数据集配置（画风）
├── output\                 ← ★ 训练出来的 LoRA 在这里
└── tools\jsonl2txt.py      ← 打标结果转换工具
```

用到的模型（和 ComfyUI 共用，不额外占空间）：

| 用途 | 文件 |
|---|---|
| 训练底模（RAW bf16） | `ComfyUI\models\diffusion_models\krea2_raw_bf16.safetensors` (24.5GB) |
| VAE | `ComfyUI\models\vae\qwen_image_vae.safetensors` |
| 文本编码器（训练/打标） | `ComfyUI\models\text_encoders\qwen3vl_4b_bf16.safetensors` |
| 出图用底模（Turbo fp8） | `ComfyUI\models\diffusion_models\krea2_turbo_fp8_scaled.safetensors` |

> ⚠️ **训练/缓存必须用 bf16 版权重**（`*_bf16.safetensors`），ComfyUI 推理用的
> `*_fp8_scaled.safetensors` **不能拿来训练**——它里面带 `weight_scale` / `comfy_quant` 量化元数据，
> 加载时会直接报：
> ```
> RuntimeError: Error(s) in loading state_dict ... Unexpected key(s): "blocks.0.attn.wq.weight_scale" ...
> ```
> DiT 和文本编码器都一样（实测踩过，本套脚本已全部指向 bf16 版）。
> 好消息：bf16 和 fp8 放在同一个 models 目录里，ComfyUI 那边照旧用 fp8（省显存），训练这边用 bf16，互不影响。

## 三、四步走

### Step 1　准备数据集

1. 收集 **15~40 张**同一角色的图（PNG/JPG 都行，**分辨率 ≥1024**，尽量清晰）
2. 全部丢进 `dataset\character\`，命名随意（建议 `01.png`、`02.png`…）
3. 写描述，两种方式：
   - **自动**：双击 `1-自动打标.bat`（用 Qwen3-VL 生成），然后**务必人工过一遍**、删掉不需要的细节
   - **手动**：给每张图建一个**同名 .txt**，里面写英文描述

   描述写法（角色 LoRA）：先说触发词，再说画面内容，**不要**写画质词

   ```
   mychar, a girl with long silver hair and red eyes, wearing a black coat,
   standing in the rain, looking at viewer
   ```

   > `mychar` 就是你的触发词，随便起（英文小写、越独特越好），
   > 之后在 ComfyUI 里出图时把它写在提示词最前面。

### Step 2　缓存

双击 `2-缓存latent.bat` → 等它跑完（第一次会加载 VAE，约 1 分钟）
再双击 `3-缓存文本编码.bat` → 完成（约 1 分钟）

> 缓存文件写在 `dataset\.cache_character\`，改了图片/描述就要删掉重跑。

### Step 3　训练

双击 `4-开始训练-LoRA.bat`，窗口里会滚动 loss。

- **20 张图 × num_repeats 10 × 16 轮 = 3200 步**，5090 上实测 **3.5 秒/步 → 约 3 小时**
  （建议先改成 4 轮跑一轮试水，看看出图方向对不对）
- **每个 epoch 都会存一个 LoRA**：`output\mychar-000001.safetensors`、`-000002`…
  最后还有一个 `mychar.safetensors`（最终版）
- **中途想停**：Ctrl+C 或直接关窗口，已经存下的 LoRA 都能用

### Step 4　出图看效果

两种方式，随便挑：

- **A. 直接出图**：双击 `5-用新LoRA出图.bat`（用 RAW bf16 模型，28 步 CFG 5.5，出 2 张到 `output\samples\`）
- **B. 装进 ComfyUI 用工作流出图**（推荐，快得多）：
  双击 `6-把LoRA装进ComfyUI.bat` → LoRA 会被复制到 `ComfyUI\models\loras\krea2\trained\`
  → 打开工作流 **`Krea2二次元`**，在「Krea2 LoRA 组合槽位」里选 `krea2\trained\你的LoRA`，权重 0.8~1.0
  → 提示词里写上触发词，8 步就能出图（约 25 秒）

**对比挑版本**：把 `output\` 里不同 epoch 的 LoRA 都试一遍，
哪个 epoch 效果最好就用哪个——**不是越晚越好**，通常会过拟合。

## 三点五、实测数据（本机验证过，2026-09-26）

| 环节 | 实测结果 |
|---|---|
| 环境 | Python 3.11.9 + torch 2.7.0+cu128（复用，没重下）+ transformers 4.57.6 + **bitsandbytes 0.50.2**（8bit 优化器可用） |
| 缓存 latent | 4 张图 **约 3 秒**（VAE 加载另计 ~10 秒） |
| 缓存文本编码 | 4 张图 **约 5 秒**（首次需从 HF 下 Qwen3-VL 的 config/tokenizer） |
| **训练** | **3.5 秒/步**（bf16 底模 + `--fp8_base --fp8_scaled` + gradient checkpointing，batch 1，1024×1536） |
| 单轮耗时 | 4 张图 × repeats 10 = 40 步 → **2 分 20 秒**，loss 0.0885 → 0.0855（在降） |
| LoRA 体积 | rank 8 → **112 MB**（rank 32 约 400~450MB，和官方风格 LoRA 0.44GB 一致） |
| **训练→出图闭环** | 训好的 LoRA 复制进 ComfyUI 后，「Krea2二次元」工作流直接选中并出图成功（**24 秒/张**） |

> 训练全程显存占用约 20~24GB（32GB 卡有余量，不需要 block swap）。

## 四、参数详解（想调就改 `4-开始训练-LoRA.bat` 里的变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `NAME` | `mychar` | 输出 LoRA 文件名 |
| `EPOCHS` | `16` | 轮数；图少可以加大，图多（50+）用 8~10 |
| `DIM` | `32` | LoRA 秩；官方推荐 32（=alpha），想更强可到 64 |
| `LR` | `1e-4` | 学习率；角色 LoRA 1e-4，画风 LoRA 建议 5e-5 |

固定参数（一般不用动）：

| 参数 | 值 | 为什么 |
|---|---|---|
| `--timestep_sampling shift` + `--discrete_flow_shift 2.5` | 2.5 | 对齐 K2 在 1024×1024 的推理时间步偏移 |
| `--network_module networks.lora_krea2` | — | **必须**，Krea 2 专用 LoRA 实现 |
| `--fp8_base --fp8_scaled` | — | DiT 权重压成 fp8，显存直接省一半（两个必须同时写） |
| `--gradient_checkpointing` | — | 用时间换显存 |
| `--optimizer_type adamw8bit` | — | 8bit AdamW，省显存 |

## 五、显存不够怎么办（32G 一般够，不够按顺序加）

1. 加 `--blocks_to_swap 8`（把 8 个 block 丢到内存，最大 26；越大越省显存、越慢）
2. 降低数据集分辨率：`dataset_character.toml` 里 `resolution = [768, 768]`
3. `batch_size` 保持 1

## 六、想同时出训练预览图

在 `4-开始训练-LoRA.bat` 的 `"%ACC%" launch ...` 后面加：

```
--text_encoder "%QWEN_BF16%" --turbo_dit "%TURBO%" ^
--sample_prompts "%ROOT%\config\sample_prompts.txt" --sample_every_n_epochs 2
```

`config\sample_prompts.txt` 一行一个提示词（Turbo 模型用 `--l 1 --s 8`）：

```
mychar, a girl with long silver hair, standing on a rooftop at sunset  --w 1024 --h 1024 --s 8 --l 1
```

> 注意：`--turbo_dit` 和 `--blocks_to_swap` **不能同时用**。

## 七、常见报错

| 报错 | 原因 / 解决 |
|---|---|
| `Unexpected key(s): "blocks.0.attn.wq.weight_scale"` | 用了 fp8_scaled 权重，**换成 bf16 版** |
| `checkpoint did not match the model: unexpected=[...comfy_quant...]` | 同上，文本编码器也要 bf16 版 |
| `--text_encoder` 找不到 | 只有生成预览图/出图才需要它，训练本身不需要 |
| loss 一直是 0 或不降 | 描述没写对/图太糊；确认 `.txt` 和图片**同名**、编码是 UTF-8 |
| 显存 OOM | 见第五节 |
| 出图完全没变化 | LoRA 权重给太低，或触发词没写进提示词 |
| 缓存报错 | 删掉 `dataset\.cache_character\` 重跑 Step 2、3 |
| `bitsandbytes` 相关报错 | 把 `--optimizer_type adamw8bit` 换成 `--optimizer_type AdamW`（更吃显存） |
| pip 装包失败 | 清华源会 403，本机已改用**阿里云源**（`https://mirrors.aliyun.com/pypi/simple/`） |

## 八、训练好的 LoRA 怎么用到 ComfyUI 工作流

1. 把 `output\mychar.safetensors` 复制到 `<ComfyUI>\models\loras\krea2\`
2. 打开工作流 **`Krea2二次元`**，在 **「Krea2 LoRA 组合槽位」** 节点里选到它，权重 0.8~1.0
3. 提示词里写上触发词（`mychar`），或用「Krea2 提示词预设」选好风格后，在「追加描述」里补 `mychar, ...`

## 九、进阶方向

- **画风 LoRA**：把 `config\dataset_style.toml` 里的 `image_directory` 指到你的画风图集，
  训练命令把 `--dataset_config` 换成它，`LR` 降到 5e-5，`EPOCHS` 8~12
- **更强表达力**：`DIM=64`（alpha 也改成 64），代价是显存和过拟合风险都上升
- **只用 attention 层**（官方"长时间训练"配置）：
  ```
  --network_args "exclude_patterns=['.*\.mlp\..*','first','last\.linear','tmlp\..*','txtmlp\..*','tproj\.1','txtfusion\..*']"
  ```
- **加速**：装 `triton-windows` 后可加 `--convrot_int8`（int8 量化底模，速度更快）；
  或 `--compile` 编译 28 个主 block
- **训练后合并/转换**：`musubi-tuner\merge_lora.safetensors`、`convert_lora.py` 可用于合并与格式转换
